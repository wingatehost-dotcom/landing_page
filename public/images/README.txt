IMAGE SLOTS — Wingate College One Member PLC
============================================

All paths below live in /public. Swap a file in place (same filename) or edit
the single reference in src/config/images.ts. Never hotlink external images.

Recommended formats: JPEG (photos) or PNG (logo/favicon). Use descriptive alt
text in src/config/images.ts.

Source originals for the newer division photos are kept outside the web root in
/source-photos so they are not copied into the static export. Replace the
optimised files below if you want to re-crop them.
